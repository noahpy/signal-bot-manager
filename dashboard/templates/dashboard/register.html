How it works
  1. Open signalcaptchas.org/registration/generate.html, solve the captcha. Right-click the “Open Signal” link → Copy link. It starts with signalcaptcha://. Paste it below immediately — it expires after about a minute.
  2. Step 1 asks Signal for an SMS. A landline can't receive it — that's expected, Signal just requires this before a call.
  3. After ~1 minute, Step 2 makes Signal call the number. Pick up: a voice reads a 6-digit code (repeated). Signal may ask for a fresh captcha here too.
  4. Step 3: enter the code. Done.

Registering makes this server the account's main device. You can link Signal Desktop to it afterwards (bottom of this page).
